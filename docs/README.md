## Documentation Structure

The documentation is organized to support different learning paths and reference needs:

### For New Users

If you're new to DataSightPro, we recommend starting with the [Getting Started](GettingStarted.md) guide, which will walk you through installation and your first analysis. This gives you a quick overview of the key functionality without overwhelming you with details.

### For Regular Users

The [User Guide](UserGuide.md) provides comprehensive step-by-step instructions for all features, organized by functional area. Once you're familiar with the basics, use the [Quick Reference](QuickReference.md) for quick reminders and shortcuts for common tasks.

### For Developers and Technical Users

The [Technical Report](TechnicalReport.md) explains the architecture, design decisions, and implementation details of DataSightPro. This is useful if you want to understand how the application works or create extensions.
